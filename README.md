# CW75 Skills Repository

Welcome to the **CW75 Skills** repository! This repository contains a collection of specialized skills designed to enhance the capabilities and workflows of AI agents. 

## Available Skills

| Skills | descriptions | AI agents workspace benefits |
| ------ | ------------ | ---------------------------- |
| **ai-memory-storager** | Manages persistent memory using Obsidian vaults with a `MEMORY.md` Map of Content (MOC) linked to `AGENTS.md`. | Maintains work progress across sessions, captures learned knowledge to prevent repeated errors, and provides structured knowledge graph visualization (via Graphify) to improve context retrieval. |
